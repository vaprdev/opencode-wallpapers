# Changelog

## 0.1.0

First npm release. Install with `opencode plugin add opencode-wallpapers`.

- Seven animated wallpapers: ocean, desert, jungle, space, farm, tundra and beach.
- Three activity levels (calm, lively, teeming) and three times of day (day, sunset, night), plus auto, which follows
  the local clock.
- The `/wallpaper` menu and command palette entries; choices are kept across restarts.
- Optional kitty graphics pixel mode.
